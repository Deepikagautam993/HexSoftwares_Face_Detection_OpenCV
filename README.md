# 🤖 HexSoftwares | Face Detection using OpenCV in Python

## 📌 Project Overview

The **Face Detection System** is a Computer Vision project developed using Python and OpenCV under **HexSoftwares**.
This system detects human faces in real-time using a webcam and highlights detected faces with bounding boxes.

The application uses a pre-trained **Haar Cascade Classifier**, a machine learning-based object detection algorithm widely used for detecting faces in images and video streams.

This project demonstrates the practical implementation of computer vision techniques and real-time image processing.

---

## 🎯 Project Objectives

* Detect human faces in real-time using a webcam

## ⚙️ Installation and Setup

```

```

### Step 2 — Install Required Libraries

```
pip install -r requirements.txt
```

### Step 3 — Run the Application

```
python face_detection_ui.py
```

---

## 🧪 How It Works

1. The system accesses the webcam
2. Captures video frames in real-time
3. Converts the frame into grayscale
4. Applies the Haar Cascade classifier
5. Detects faces in the frame
6. Draws rectangles around detected faces
7. Saves detected faces into the detected_faces folder
